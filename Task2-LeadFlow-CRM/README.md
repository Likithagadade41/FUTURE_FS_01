# LeadFlow CRM

A full-stack Client Lead Management System (Mini CRM) built to manage leads, track their status, schedule follow-ups, and view lead analytics.

## Features

- Lead management
- Lead status tracking
- Follow-up management
- Analytics dashboard
- Follow-up calendar
- MongoDB database
- Responsive CRM interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Netlify Functions
